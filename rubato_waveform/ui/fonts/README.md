# Vendored fonts

The app makes no web requests at runtime, so the fonts ship with it.

| Font | Source package | Subset | Licence |
| --- | --- | --- | --- |
| Instrument Sans (variable, wght 400-700) | `@fontsource-variable/instrument-sans` 5.3.0 | Latin, normal style | SIL OFL 1.1, see `OFL-InstrumentSans.txt` |
| JetBrains Mono (variable, wght 100-800) | `@fontsource-variable/jetbrains-mono` 5.3.0 | Latin, normal style | SIL OFL 1.1, see `OFL-JetBrainsMono.txt` |

Neither font declares a Reserved Font Name. The files are unmodified copies of
`files/*-latin-wght-normal.woff2` from the packages.
